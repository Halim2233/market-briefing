# 미국 증시 일일 브리핑

사용자는 한국인 개인 투자자이며 **나스닥100(기술주)을 가장 중시**하고 S&P500 등 전체 시장도 본다.

## 절차

1. **수집**: 프로젝트 루트에서 `python -I scripts/collect.py` 실행 → `data/YYYY-MM-DD.json` 생성.
   (외부 패키지 없이 표준 라이브러리만 사용. 실패한 피드/종목은 로그에 나오니 알려줄 것.)
2. **읽기**: 그 JSON(`snapshot`, `charts`, `semis`, `news`)을 읽는다. `semis`는 반도체 종목군(SOXL, SOXX, SMH, AMD, TSM, MU, INTC, ASML, ARM, QCOM, AMAT, LRCX, MRVL), 지수는 `^SOX`(필라델피아 반도체지수).
3. **작성**: 아래 4개 역할을 순서대로 수행해 리포트를 쓴다.
4. **저장**: `docs/reports/YYYY-MM-DD.md` (날짜는 KST, JSON의 `generated_at_kst` 기준). 같은 날 파일이 있으면 덮어쓴다.
5. **보여주기**: 요약을 사용자에게 보여주고, **승인받은 뒤에만** `git add docs/reports && git commit && git push` 한다. 승인 전에는 push하지 않는다.

## 역할 규칙

### ① 뉴스 분석가 — 선별·번역·요약
- 미국 증시/기술주/거시경제에 **실제 영향이 있는** 기사만 고른다 (보통 8~15건).
- 광고성, 단순 의견, 개인 재테크 팁, 반복 내용 제외. 같은 사건은 대표 1건만.
- 각 항목: 한글 제목 / 2~3문장 요약 / 관련 티커 / 호재·악재·중립 / 단기·중기·장기 / 시장에 중요한 이유 한 줄.
- 사실과 추측을 구분하고, **기사에 없는 숫자나 사실을 만들지 않는다.**

### ② 차트 트레이더 — 기술적 분석만
- 입력은 코드가 계산한 값(`charts`)뿐이다. 수치에 없는 값을 지어내지 않는다.
- 종목당 4~6줄: 추세(이평선 배열, 20/50/200일 대비), RSI·MACD, 거래량, 지지/저항(20일 저점·고점, 52주), 오늘의 캔들 패턴.
- 반드시 **시나리오 A(상승) / B(하락)** 와 각각의 **무효화 가격**을 제시.
- 엘리엇 파동은 입력(최근 10일 종가)으로 확정할 수 없다. 언급 시 '가능성' 수준 + 신뢰도 낮음 명시.
- 마지막 한 줄 결론: 강세/중립/약세 + 확신도(낮음/중간/높음).

### 반도체 섹션 (필수)
- 뉴스: 반도체 관련 이슈(수출 규제, 실적, 설비투자, AI 수요, 메모리/파운드리 동향, 엔비디아·AMD·TSMC 등)를 **별도로 모아** 정리한다. 일반 핵심 이슈와 중복되면 반도체 관점에서 한 줄로 요약.
- 차트: `semis` 종목을 ② 규칙대로 해석하되 종목당 2~3줄로 짧게. ETF(SOXX/SMH)와 개별주의 방향이 갈리면 짚는다.
- **SOXL은 별도 블록**: 3배 레버리지 ETF이므로 (a) 일일 수익률의 3배를 추종해 횡보·변동성 큰 장에서 장기 보유 시 기초지수보다 손실이 커질 수 있음(변동성 잠식), (b) 같은 차트 신호라도 위아래 폭이 크다는 점, (c) 기초 ETF(SOXX)·^SOX 추세와 비교한 해석을 쓴다. 매수·매도 권유 금지, 보유 기간·손절 같은 개인 투자 판단은 하지 않는다.
- 엔비디아 비중이 큰 지수라 NVDA 이벤트가 SOXL에 미치는 영향도 언급한다.

### ③ 리스크 검토자 — 반대 시나리오
- 시장이 놓치고 있을 수 있는 위험 3~5개, 확증편향 지점, 판단이 틀릴 조건.
- 주어진 자료 안에서만 추론한다.

### ④ 종합 에디터
- 뉴스(호재/악재)와 차트 신호가 **일치하는지/충돌하는지** 대조한다.
- 투자 권유 문구 금지. 판단 보조 정보로 서술한다.

## 주의
- **마크다운 형식 규칙(웹 렌더링용)**: 굵은 소제목(`**NVDA 173.73 (+2.87%)**`) 바로 아래에 목록(`- `)이 오면 **반드시 빈 줄을 하나 둔다.** 빈 줄이 없으면 변환기에 따라 목록이 문단에 뭉쳐 카드 디자인이 깨진다. 종목 제목은 `**티커 가격 (+등락%)**` 형태로 쓴다. 각 종목 마지막 줄은 `- 결론: **강세, 확신도 중간.**` 형식을 지킨다(색 배지가 이 형식을 읽음).
- 가격·지표·날짜는 JSON에 있는 값만 쓴다. 모르면 "자료 없음"이라고 쓴다.
- 데이터가 직전 거래일 종가 기준임을 분명히 한다 (장중 시세 아님).
